# Hypixel Zombies Mod

一个面向 Hypixel Zombies / 僵尸末日模式的 Fabric 客户端辅助 Mod，主要提供 HUD 信息显示、队友状态追踪、枪械切换、波次提示、实体可视化与若干游戏体验优化功能。

当前分支：

| Branch | 用途 |
| --- | --- |
| `mc-26.1.2` | 稳定版 |
| `mc-26.2-test` | 26.2 迁移测试版，可能存在兼容问题 |

## Dynamic Island

Skia 灵动岛 HUD 默认开启，进入世界后在屏幕顶部居中显示。两个任务同时运行时切为主胶囊与右侧独立小岛；展开时副岛先开始吸附，随后在合并途中展开选中任务的详情，两个动作自然重叠。两岛靠近时形成轻微的玻璃连接颈，单岛与双岛使用同一套描边、高光和折射，收起时先压回胶囊，再恢复双岛；任务结束后剩余任务平滑补位。任务进度与暂停状态独立保存。

默认内容来源为 **Live**，读取 Windows 系统媒体会话中的 **QQ 音乐**曲名、歌手、封面、播放状态及播放器提供的进度。**按住 Tab** 展开主任务，**Shift+Tab** 展开副任务，**松开 Tab** 收起；按住期间不会被自动提示收起。打开背包、聊天、设置等其他 UI 时岛仍在顶部显示，玻璃采样已绘制的 UI 背景；进入 UI 或窗口失焦时结束临时按住展开。**F8** 展开/收起主任务，**Shift+F8** 展开/收起副任务，**F9** 控制 QQ 播放/暂停，**F10** 下一首，**Shift+F10** 上一首。展开后始终显示进度条；优先使用与当前歌曲匹配的 QQ 播放栏真实时间，读取暂时不可用时回退系统媒体时间轴。读取按曲名与歌手选择 QQ 的可见主窗口，避开桌面歌词与隐藏的同名窗口；兼容时间文字外增加容器的布局，换歌立即清除旧数据并复用仍有效的时间控件。QQ 须提供可访问的播放栏数据；若首次最小化时无法取得数据，打开一次 QQ 主窗口，读取不会自动拉起窗口。两种来源均不可用时显示未知状态与 `--:--`，不编造时长。音乐暂停或停止满 30 秒后自动移除音乐岛，其他任务补位；恢复播放立即重新显示，短暂停顿保留播放控制。超时按真实经过时间计算，不随帧率变化；隐藏后继续只读媒体状态。未检测到 QQ 会话时不显示音乐岛，也不会读取其他播放器。媒体读取与控制均在后台，不阻塞游戏帧。紧凑状态文字按实际字形轮廓与封面、图标垂直居中。

进度读取兼容多歌手名称中的空格差异；只扫描播放栏附近的时间控件，避免遍历整个歌单。歌词缺失时单独重试歌词区域，保留仍有效的时间控件，减少歌词重试引起的进度中断。

进度条、歌词换句和高光使用同一帧的连续播放时钟。QQ 播放栏的整秒读数按一秒精度区间处理，重复采样不会重新计时；系统进度按其更新时间补偿，封面读取延迟也计入样本年龄。轻微误差缓慢校正，单个异常或较旧读数不能让进度回退；真正的拖动跳转经连续读数确认后同步更新，通常约一个轮询间隔（500ms）。暂停保留连续时间的小数部分，恢复时不累计暂停时间。当前歌曲临时缺失时间数据时保留已确认的时长和时钟最多 3 秒，再显示未知进度；换歌或媒体消失立即清理。

音乐条使用 Windows Core Audio 中 QQMusic 进程自身的实时音量峰值，约 30 次/秒采样，按音量历史跳动并平滑衰减，不受 Minecraft 或其他播放器音效驱动。五条采用不同采样延迟、较大的伸缩幅度、快速起跳和回落；扩大音量差异并增强弱音响应，让节奏起伏更明显。暂停、静音或无法取得音量时变为短条。颜色从封面提取两种柔和色调，渐变用于音乐条和进度条；换歌时平滑过渡。展开后的底部快捷键提示已移除。

灵动岛设置新增 **显示歌词 / Show Lyrics**，默认关闭。开启后收起状态的歌曲名位置显示当前歌词，换句淡入切换，岛宽按字体实际测量结果弹性伸缩；单任务宽度为 138–280、双任务主岛为 124–232 个岛内逻辑像素，再随 HUD 比例与窗口缩放，给封面、音乐条和副岛留出空间。同步歌词以真实播放位置推进柔和封面色高光，未唱部分为浅灰；增强 LRC 中已有的逐字时间戳按字词边界推进，使用实际字形宽度定位高光，结束时间标签可让整句在句间停顿前唱完。只有逐句时间戳时仍采用句内插值，无法精确还原每个字的唱法。新增「高光提前 (ms) / Highlight Advance (ms)」，默认 250ms，可在 -2000–2000ms 范围内微调；正数提前、负数延后，只改变句内高光及跟随它的滚动，不改变歌曲进度、换句时间或歌词宽度。超长句随高光位置滚动，无时间戳的原生歌词保留普通往返滚动，暂停时两者停止。展开后仍显示曲名和歌手。优先只读 QQ 播放栏的歌词区域，不依赖桌面歌词；只有开启此选项、真实时长可用时，后台按曲名、歌手及真实时长从 LRCLIB 获取同步歌词，供缺失歌词回退或匹配原生句子的高光计时使用。原文、译文与原文加译文按同一时间戳分组，统一使用下一个不同时间戳作为句尾；标点、全角字符、零宽字符及增强 LRC 的时间标签不影响匹配。相邻句允许最多 1 秒的 QQ 文字采样偏差，但保留原时间区间与播放时钟。QQ 省略文本或译文无法匹配时，改用已验证歌曲版本的同步句子，避免个别歌词突然失去高光；整首歌曲缺少同步数据时仍保留原生文本，不猜测计时。内存缓存最多 16 首，失败后限频重试，支持暂停、跳转与换歌清理；无可用歌词时回退歌曲名。不会修改 QQ 设置或下载音频。

播放栏与系统会话的时长存在最多 2 秒的取整差异时，继续使用已经验证的歌词计时，避免高光间歇退回普通文字。容差始终对首次验证的版本比较，不随每次读数累积；时间轴暂时不可用时保留该歌曲的歌词缓存，恢复后立即复用。真实换歌、明显不同的歌曲时长或关闭歌词仍清除旧计时；未知时间轴不虚构高光位置。

启用 **Wave Display** 后，音乐占主胶囊，原来的波次 HUD 保留并与岛同时显示。Wave 岛仅在下一波最后 3 秒倒计时开始时出现；等待期间及清场时隐藏，结束后完成数字淡出再退场。右侧圆形副岛的琥珀色圆环随下一波倒计时缩短，中心不再显示 Round，仅在最后三秒依次显示 3、2、1；数字切换时旧数字模糊、缩小退场，新数字淡入并轻微弹性落定，结束后淡出，圆环保持连续计时；其他时间及清场时不显示数字，每次出波按新的实际间隔重新计时。Tab 展开音乐，Shift+Tab 查看波次时间轴与 Boss 提示。启用 **Revive Aura** 并实际发起新救援后，救援以最高提示优先级自动合并展开 3.2 秒，显示队友、服务器确认状态和独立进度；随后恢复音乐主岛，副岛改为绿色救援进度环，Shift+Tab 可再次展开救援。三任务同时进行时 Wave 保留并持续更新，其摘要显示在救援详情底部及展开的音乐底部，未开启歌词时也显示在紧凑音乐胶囊中。救援结束自动恢复波次倒计时副岛；没有音乐时救援为主岛、Wave 为副岛。手动按住 Tab 时不抢走所选任务；「自动短暂展开」可关闭，关闭后新救援直接进入紧凑布局。下一波倒计时不再触发 Wave 自动展开，仍可手动展开查看详情，没有真实任务时整个岛隐藏。

右 Shift →「灵动岛 / Dynamic Island」可单独关闭 QQ 音乐、波次/复活接入，调整大小与顶部距离。**按住展开按键 / Hold To Expand** 默认 Tab，**切换展开按键 / Toggle Expansion** 默认 F8；点击对应按钮后按新键或鼠标侧键即可绑定，Esc 清除绑定，自动保存到配置。Shift 配合自定义按键选择副岛；展开快捷键仅在游戏操作时生效，避免干扰 UI 输入。波次接入始终保留原 Wave HUD，复活接入后对应原 Revive HUD 隐藏；关闭复活接入、灵动岛或切到 Demo 时恢复原 Revive HUD，模块功能及音效不变。**Source / 内容来源**切到 **Demo** 可恢复 F9 切示例、F10 开关第二任务的旧演示。退出世界、禁用模块和退出游戏会清理读取进程及 Skia 资源。QQ 接入使用系统自带 Windows PowerShell 5.1，不需要登录 QQ 或提供账号信息；播放器须发布 Windows 媒体会话。

独立预览可通过灵动岛设置中的「独立预览 / Open Preview」打开：点击或长按任一岛查看对应任务，**M** 开关第二任务，**Shift+Space** 展开副岛，**1–3** 切换主任务，**S** 慢放，**A** 自动演示，**Esc** 返回。「End focused activity」可结束当前任务并查看补位动画。

外壳采用透明液态玻璃，实时折射与轻度模糊游戏背景，带细边高光和柔和阴影。包含弹性形变、内容模糊与缩放、场景交叉淡化和可中断动画。详见 [演示说明](tools/dynamic-island/README.md)。

## Features

### Combat

| Module | 功能 |
| --- | --- |
| Auto Switch Weapon | 根据枪械配置自动切换武器，支持冷却模式与换弹辅助 |
| Right Clicker | 右键连点器，可限制只对枪械生效 |
| No Gun Fire | 屏蔽开枪时的火焰遮挡 |
| Damage Numbers | 显示伤害与金币数字，支持按武器和强化状态区分颜色 |
| DPS Counter | 实时统计 DPS，便于测试输出效率 |

### Zombies HUD

| Module | 功能 |
| --- | --- |
| Target Hud | 显示当前目标血量、距离等信息 |
| Wave Display | 显示 AA 波次，并用箭头标记当前波 |
| Teammates Glow | 队友高亮与队友信息显示 |
| Lightning Rod Queue | 记录团队 Lightning Rod 使用队列与 20 秒冷却 |
| Stats Query | 查询玩家 Zombies 战绩 |
| AA Powerup Predictor | 预测 AA 道具掉落 |
| Notification | 回合计时与 AA 回合建议提示 |
| Dynamic Island | 顶部居中的透明液态玻璃灵动岛，支持背景折射、弹性展开和内容模糊过渡 |

### Visual / Render

| Module | 功能                             |
| --- |--------------------------------|
| Zombie Chams | 僵尸穿墙显示                         |
| Bad Headshot | 标记无法正常暴击的实体，并用红色碰撞箱标记出来        |
| Hide Blocking Player | 玩家重叠遮挡时自动隐藏                    |
| Hide Zombies | 僵尸靠近遮挡时自动隐藏，LS时能看清楚            |
| No Fire Effect | 降低或去除屏幕火焰遮挡                    |
| Hologram Fix | 改善 Zombies 全息文字交互体验，支持忽略方块右键反应 |

### Utility

| Module | 功能 |
| --- | --- |
| Sprint | 强制疾跑 |
| Name Protect | 名字保护 |
| Hud | 基础 HUD 显示与调试入口 |

## Notes

- 本项目主要针对 Hypixel Zombies / 僵尸末日玩法开发。
- 功能依赖记分板、聊天消息、监听发包事件, 但不存在修改服务器发包等操作。
- 大部分功能为改本地客户端（即Mod行为），不存在任何改包操作，因此基本不会有封禁风险
